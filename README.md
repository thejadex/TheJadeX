<h3 align="center">Software Engineer · Backend Engineering · AI Evaluation</h3>

I build software with a strong focus on **correctness, reliability, and system behavior**.

My work spans backend engineering, repository-level debugging, automated testing, AI coding evaluation, and designing technical problems that expose where software — or the models writing it — actually breaks.

I'm particularly interested in the engineering beyond simply *making code work*: understanding failure modes, defining invariants, testing edge cases, and building software that remains correct under real-world conditions.

---

## ⚡ What I'm working on

- 🧠 **AI Coding Evaluation & Benchmark Design** — designing and evaluating repository-level engineering problems for coding agents
- 🐍 **Python & Django** — backend applications, APIs, database integrity, transactional correctness, and testing
- 🟣 **C# & .NET** — deepening my knowledge of the ecosystem while applying strong software engineering fundamentals
- 🧪 **Software Reliability** — debugging, regression prevention, adversarial testing, fuzzing, and failure analysis
- ✅ **Software Correctness** — reasoning about invariants, edge cases, concurrency, data integrity, and failure behavior
- 🤖 **AI-Assisted Engineering** — using AI as an engineering tool while keeping architecture, verification, security, and correctness human-led
